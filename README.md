# Momentum

A minimalist life-goals app. Categories of goals, each with a roadmap of steps; key-date countdowns; daily nudges. Installable as a PWA.

**Privacy:** this repository contains only the app code. Your goals are stored on your device and, optionally, in a private GitHub Gist you control. Nothing personal is committed here.

Deployed automatically to GitHub Pages by `.github/workflows/pages.yml` (which also renders the PNG icons from the SVG sources).
